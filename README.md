# Morphogenetic Buds Clustering (MBC)

This repository contains the source code, datasets, experimental results, and figures for the Morphogenetic Buds Clustering (MBC) algorithm.

The manuscript is not included in this repository.

## Overview

Morphogenetic Buds Clustering (MBC) is a clustering algorithm inspired by biological morphogenesis. This repository provides the implementation of MBC and the experimental pipeline used to compare MBC with other clustering algorithms.

The experiments include:

- Main benchmark experiments
- Ablation experiments
- Parameter sensitivity analysis
- Runtime analysis
- Real-world dataset experiments
- Hyperspectral data experiments
- Clustering visualization

## Repository Structure

- `code/`: MBC implementation and experiment scripts
- `data/`: datasets used in the experiments
- `docs/`: dataset sources and reproduction instructions
- `figures/paper_previews/`: prepared figures for presentation
- `figures/experiment_results/`: selected figures generated by the experiments
- `results/paper_results/`: numerical results and generated experiment outputs
- `requirements.txt`: required Python packages
- `README.md`: repository documentation

- `code/morphogenetic_buds_clustering.py`: core implementation of the MBC algorithm
- `code/run_all_experiments.py`: complete experimental pipeline
- `code/export_submission_datasets.py`: dataset preparation and export
- `code/paper_experiments_mbc.py`: main benchmark and ablation experiments
- `code/sensitivity_mbc.py`: parameter sensitivity experiments
- `code/runtime_and_bio_visuals_mbc.py`: runtime analysis and biological data visualization
- `code/external_real_benchmark_mbc.py`: experiments on external real-world datasets

- `code/analyze_yyc200.py`: analysis of the YYC200 hyperspectral dataset
- `code/publication_cluster_figures.py`: generation of clustering figures
- `code/publication_advanced_figures.py`: generation of additional experimental figures

## Running the Experiments

Open a terminal in the root directory of this repository and run:

`python code/run_all_experiments.py --paper-only`

The `--paper-only` option runs the main reproducibility experiments and excludes the legacy demonstration scripts. It does not download or include the manuscript.

The experimental pipeline includes:

- Dataset preparation
- Main benchmark experiments
- Ablation experiments
- Parameter sensitivity analysis
- External real-world dataset experiments
- Runtime experiments
- Biological data visualization
- YYC200 hyperspectral data experiments
- Experimental figure generation

The generated numerical results are mainly saved in:

`results/paper_results/`

Generated and selected figures are saved under:

`figures/`

## Experimental Validation

The validation experiments compare MBC with other clustering algorithms on multiple synthetic and real-world datasets.

The main evaluation metric is the Adjusted Rand Index (ARI). A higher ARI generally indicates that the clustering result is closer to the ground-truth class labels.

The validation mechanism includes:

- Main benchmark comparison across multiple datasets
- Comparison of average ARI and algorithm rankings
- Ablation experiments for evaluating the contribution of MBC components
- Parameter sensitivity analysis for evaluating algorithm stability
- Runtime scaling analysis
- Statistical tests, including Friedman and Wilcoxon tests
- Visualization on biological and non-convex datasets
- Hyperspectral data analysis

## Datasets

The repository contains the datasets required for the main experiments, including:

- Synthetic benchmark datasets
- scikit-learn benchmark datasets
- OpenML datasets
- NHANES data
- YYC200 hyperspectral data

Detailed information about dataset sources is provided in:

`docs/dataset_sources.md`

Ground-truth labels are used only for evaluating clustering results and are not used to fit the clustering algorithms.

Some OpenML datasets may require an internet connection if they are not already available in the repository or local cache.

## Reproducibility Note

Experimental results may vary slightly across different computers because of differences in operating systems, Python versions, package versions, numerical libraries, and random initialization.

Therefore, results regenerated in a new environment may not be exactly identical to the saved results. However, the experimental procedure, evaluation metrics, and algorithm comparison mechanism remain the same.

## Repository Contents

This repository contains only the code, datasets, figures, and experimental results required for reproducing the MBC experiments.

The manuscript, LaTeX source files, review documents, and other submission materials are not included.
