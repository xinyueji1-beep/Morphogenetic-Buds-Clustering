# Dataset Sources

## Main Benchmark Datasets

| Dataset | Source | Access |
|---|---|---|
| Iris | scikit-learn built-in | `sklearn.datasets.load_iris()` |
| Wine | scikit-learn built-in | `sklearn.datasets.load_wine()` |
| Breast Cancer Wisconsin | scikit-learn built-in | `sklearn.datasets.load_breast_cancer()` |
| Digits 0-4 | scikit-learn built-in | `sklearn.datasets.load_digits()` filtered to labels 0-4 |
| Two Moons | scikit-learn synthetic | `sklearn.datasets.make_moons()` |
| Circles | scikit-learn synthetic | `sklearn.datasets.make_circles()` |
| Varied Density | generated by project script | `paper_experiments_mbc.py::make_varied_density()` |
| Anisotropic Blobs | scikit-learn synthetic + linear transform | `sklearn.datasets.make_blobs()` |

## Notes

- Ground-truth labels are used only for evaluation metrics, not for fitting clustering models.
- Adult and Bank Marketing are downloaded from OpenML when available and are stratified to at most 3000 samples for runtime control.
- The repository includes cached OpenML datasets under `data/raw/openml/`.
- NHANES is stored under `data/public_data/nhanes.csv`.
- Main benchmark datasets are stored under `data/raw/main_benchmark/`.
- Processed datasets can be regenerated by running `code/export_submission_datasets.py`.
- The YYC200 hyperspectral dataset is stored under `data/yyc200_hyperspectral/`.
- `data/dataset_manifest.csv` and `data/dataset_manifest.json` describe the experiment datasets and their sources.
