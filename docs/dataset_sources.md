# Dataset Sources

This file describes the datasets that are used by the bundled code and results. The raw and processed
caches are included in `data/`, so the reported analyses can be rerun without downloading data. The
ground-truth labels are used only for evaluation, never to fit the clustering models.

## Primary Benchmark

The primary benchmark contains 15 datasets or generators, evaluated with seeds `3, 7, 11, 19, 23`.

| Dataset | Source or generator | Bundled location |
|---|---|---|
| Iris | scikit-learn `load_iris` | `data/raw/main_benchmark/iris_seed*.csv` |
| Wine | scikit-learn `load_wine` | `data/raw/main_benchmark/wine_seed*.csv` |
| Breast Cancer Wisconsin | scikit-learn `load_breast_cancer` | `data/raw/main_benchmark/breast_cancer_seed*.csv` |
| Digits 0-4 | scikit-learn `load_digits`, filtered to labels 0-4 | `data/raw/main_benchmark/digits_0_4_seed*.csv` |
| Two Moons | scikit-learn `make_moons` | `data/raw/main_benchmark/two_moons_seed*.csv` |
| Circles | scikit-learn `make_circles` | `data/raw/main_benchmark/circles_seed*.csv` |
| Noisy Moons | scikit-learn `make_moons` with higher noise | `data/raw/main_benchmark/noisy_moons_seed*.csv` |
| Noisy Circles | scikit-learn `make_circles` with higher noise | `data/raw/main_benchmark/noisy_circles_seed*.csv` |
| Varied Density | Project generator `make_varied_density` | `data/raw/main_benchmark/varied_density_seed*.csv` |
| Anisotropic Blobs | scikit-learn `make_blobs` plus a fixed linear transform | `data/raw/main_benchmark/anisotropic_blobs_seed*.csv` |
| Ecoli | OpenML cached table | `data/raw/main_benchmark/ecoli_seed*.csv` |
| Glass | OpenML cached table | `data/raw/main_benchmark/glass_seed*.csv` |
| Vehicle | OpenML cached table | `data/raw/main_benchmark/vehicle_seed*.csv` |
| CMC | OpenML cached table | `data/raw/main_benchmark/cmc_seed*.csv` |
| WDBC | OpenML cached table | `data/raw/main_benchmark/wdbc_seed*.csv` |

The corresponding matrices after standardization and optional PCA are stored under
`data/processed/main_benchmark/`.

## External Real-Data Benchmark

The external benchmark uses three seeds, `3, 7, 11`, and the following cached OpenML datasets. The
OpenML identifiers are retained in `data/dataset_manifest.json`.

| Dataset | OpenML ID | Role | Bundled location |
|---|---:|---|---|
| MiceProtein, 8-class labels | 40966 | Labeled biological case | `data/processed/external_real_benchmark/MiceProtein_8class_processed.csv` |
| MiceProtein, genotype labels | 40966 | Exploratory factor label | `data/processed/external_real_benchmark/MiceProtein_genotype_processed.csv` |
| MiceProtein, behavior labels | 40966 | Exploratory factor label | `data/processed/external_real_benchmark/MiceProtein_behavior_processed.csv` |
| MiceProtein, treatment labels | 40966 | Exploratory factor label | `data/processed/external_real_benchmark/MiceProtein_treatment_processed.csv` |
| Leukemia, 2 classes | 45090 | Gene-expression case | `data/processed/external_real_benchmark/Leukemia_2class_processed.csv` |
| Leukemia, 3 classes | 45091 | Gene-expression case | `data/processed/external_real_benchmark/Leukemia_3class_processed.csv` |
| Lymphoma, 3 classes | 45094 | Gene-expression case | `data/processed/external_real_benchmark/Lymphoma_3class_processed.csv` |
| Credit-g | 31 | Real mixed tabular case | `data/processed/external_real_benchmark/credit-g_processed.csv` |
| Diabetes | 37 | Real medical tabular case | `data/processed/external_real_benchmark/diabetes_processed.csv` |
| Vehicle | 54 | Real shape-feature case | `data/processed/external_real_benchmark/vehicle_processed.csv` |
| Ionosphere | 59 | Real signal-feature case | `data/processed/external_real_benchmark/ionosphere_processed.csv` |
| Blood Transfusion | 1464 | Real medical tabular case | `data/processed/external_real_benchmark/blood-transfusion_processed.csv` |

The corresponding raw OpenML caches are under `data/raw/openml/`. The external preprocessing performs
numeric/categorical encoding, standardization, and PCA to at most 12 retained dimensions where needed.

## Additional Inventory Files

`Lung_5class` (OpenML 45093) is bundled for the Reviewer 3 dataset inventory and related diagnostics.
It is not included in the main external benchmark summary generated by the current `external_main`
runner. The raw and processed files are retained so that the inventory can be regenerated exactly.

The Asian Games Village YYC200 scene is an unlabeled ENVI BSQ hyperspectral cube bundled under
`data/yyc200_hyperspectral/`. It is used for the exploratory case study with an illustrative `K=6`,
not for reference-label accuracy claims. Its supplementary exploration images are under
`figures/hyperspectral_exploration/`.

## Reproduction and Provenance

- Run `code/reproduce_all.py` from the package root to regenerate manifests, results, and figures.
- `data/dataset_manifest.csv` and `data/dataset_manifest.json` enumerate the bundled caches.
- The main and external results are stored under `results/paper_results/`.
- Third-party datasets remain subject to their original OpenML or scikit-learn licenses and terms.
